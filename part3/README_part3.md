### Part 3 sub a. | Node.js and Express

A backend on top of NodeJS, which is a JavaScript runtime based on Google's Chrome V8 JavaScript engine.

Browsers (frontend) don't yet support the newest features of JavaScript, and that is why the code running in the browser must be transpiled with e.g. babel.

In contrast to the backend, Node supports a large majority of the latest features of JavaScript, so we can use the latest features without having to transpile our code.

*Applications and exercises in this part are not all React applications*, and we will not use the `create vite@latest -- --template` react utility for initializing the project for this application.

NPM is a tool used for managing JavaScript packages. NPM originates from the Node ecosystem.
